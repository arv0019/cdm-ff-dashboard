Local Kickoff Guide
Illustrative — Week 1
Kickoff times are converted to whichever market is selected, using each market's real IANA timezone rather than a hardcoded ET/CT/MT offset table — necessary because Phoenix is a genuine edge case: Arizona doesn't observe daylight saving time, so for most of the NFL season (roughly mid-March–early November) Phoenix's clock actually matches Pacific Time, one hour off from Denver/Mountain despite usually getting grouped with it. Switch markets on the same game to see the times shift correctly. Games are sorted by real kickoff order (Thu night → Sun early → Sun late → SNF), not by the order they're defined in code. Media market defaults to the team picked at the top (Kingdom→KC, Benchwarmers→JAX, Nifty→Columbus, Cosmic→Houston, TBDs→DFW, Yogi→Phoenix — all 6 confirmed) — change it manually to check a different one. Broadcast maps (CBS/FOX doubleheader and home-market rules), network/streaming assignments, and kickoff times aren't available via a free API — the 2026 schedule and TV rights haven't even been published yet — so the game list shown here is illustrative, built on real broadcast-rights conventions (CBS = AFC away team, FOX = NFC away team, NBC = Sunday Night Football) and a plausible Week 1 date (Sept 10–13, 2026) as a stand-in. The two violet-tagged games are streaming-exclusive (no broadcast feed at all) and, like all national windows, air in every market since there's no local-affiliate restriction. One accuracy note: Netflix's actual NFL rights are Christmas Day games, not a Week 1 fixture — it's included here only to illustrate that this panel can represent a streaming-exclusive game, not as a real prediction of the 2026 schedule. Any non-exclusive game not in your market can usually still be streamed via NFL+ on mobile. Roster overlap is real 2025 data (2026 rosters don't exist yet — draft pending) mapped against each game's NFL teams. Columbus, OH has no home NFL team, so its early window typically follows regional CBS/FOX affiliate splits rather than a single local team. Team Cosmic has no roster history yet.
About This Dashboard

This is a personal side project to explore what AI tools can do with fantasy football decisions. It draws on both public and private data.

Public data (e.g., player stats, injuries, Vegas lines, weather, coaches' tendencies) is the same information any fantasy site uses.

League-specific data includes my own roster and transactions, plus league-wide standings, scores, and other owners' rosters and transaction history. This data is used to spot league-wide patterns like waiver competition. It is not used to build behavior profiles on individual owners. All of these metrics are available to every owner in the league through ESPN or I can provide them to you. If you would like to exclude your team from league-wide analysis, let me know.

This project does not use login credentials, automate trades or waivers, or leave this league. This project is for my learning purposes only, not for commercial or gambling purposes. This project is not affiliated with ESPN, Anthropic, the NFL, or any other organization.
